IS542 test pages

Harmless test pages for a course project on how AI browser extensions handle untrusted page content. Marker word: ZK7Q. Every page is built by us; nothing here is a real attack.

Naming: <pagetype>/<hiding-spot>-<rung>.html. Spots: color, css, tiny, comment, alt, attr, button. Rungs: r1 plain, r2 authority, r3 context-aware long. control-* shows the same instruction in plain sight. baseline has no instruction.
